# the little nook

Приложение-реквизит для iPad: меню, карточка заказа, напиток дня, табличка и фоновая сцена.

## Как выложить бесплатно (GitHub Pages)

1. Зарегистрируйся на [github.com](https://github.com), если аккаунта ещё нет.
2. Нажми **+** вверху справа → **New repository**. Имя: `coffee-corner`, тип **Public**. Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Открой папку `coffee-corner` в Finder, выдели всё внутри (Cmd+A) и перетащи в окно браузера. Нужно содержимое папки, а не саму папку. Нажми **Commit changes**.
5. Открой **Settings** → **Pages**. В разделе **Branch** выбери `main`, папку `/ (root)` и нажми **Save**.
6. Через пару минут приложение будет доступно здесь: `https://ТВОЙ-ЛОГИН.github.io/coffee-corner/`

Эта ссылка публичная, но её никто не узнает, если ты её не покажешь. Твои напитки и настройки хранятся только на самом iPad и никуда не загружаются.

**Вариант проще (Netlify):** открой [app.netlify.com/drop](https://app.netlify.com/drop), войди в аккаунт и перетащи папку `coffee-corner` целиком. Получишь готовую ссылку.

## Как поставить на iPad

1. Открой ссылку в **Safari**, при включённом интернете.
2. Нажми **Поделиться** (квадрат со стрелкой) → **На экран «Домой»**. Если появится переключатель «Открывать как веб-приложение», оставь его включённым.
3. Запусти приложение с домашнего экрана и подожди несколько секунд. После этого оно работает без интернета.

На iPhone всё так же.

## Как пользоваться

- **Листать экраны:** провести пальцем влево или вправо.
- **Поменять текст:** три быстрых тапа недалеко от правого верхнего угла или удерживать там палец 2 секунды. Надписи обведутся пунктиром: нажми на нужную и печатай. Кнопка **done** возвращает обычный режим, **more** открывает напитки, сезоны и бэкап. У самого края касания не считаются.
- **Напиток дня и табличка:** короткий тап по экрану.
- **Витрина:** стрелки листают напитки, кнопка **order** создаёт новый заказ и открывает карточку заказа.
- **Оплата, звонок и записка в чашке:** короткий тап по экрану, ещё один тап возвращает всё назад.
- **Налей сам:** держи палец на экране, кофе льётся, пока не отпустишь. Тап по полной чашке опустошает её.
- **Лишние экраны:** их можно выключить в **more** → `café` → `screens`.
- **Фоновая сцена:** зависит от сезона. Зима: снег, весна: дождь на окне, осень: свеча, лето: солнечные блики.

## Перед съёмкой

- **Настройки → Экран и яркость → Автоблокировка → Никогда**, чтобы экран не погас во время дубля.
- Часы и батарею вверху экрана Apple полностью скрыть не даёт. На светлом фоне они почти незаметны.
- Чтобы случайно не выйти из приложения, можно включить **Настройки → Универсальный доступ → Гид-доступ**.

## Резервная копия

Вкладка **backup** в режиме редактирования. Safari и приложение с домашнего экрана не делят данные между собой, поэтому заполняй всё в установленном приложении и иногда сохраняй копию.

## Что можно менять самой

Открой файл в любом текстовом редакторе, сохрани и загрузи заново на GitHub (пункты 3–4).

| Что | Где |
|---|---|
| Цвета, сезонные акценты, зернистость бумаги | `css/theme.css` |
| Размеры и расположение на экранах | `css/screens.css` |
| Напитки и тексты при первом запуске | `js/defaults.js` |
| Чувствительность свайпов и касаний | начало `js/app.js` |
| Снег, дождь, свеча, блики | `js/ambient.js` |

После загрузки изменений приложение при наличии интернета сразу откроется в новой версии. Изменения в `js/defaults.js` действуют только на новую установку. То, что ты уже заполнила, меняется в режиме редактирования.

Шрифты Instrument Sans и Architects Daughter взяты из Google Fonts, они бесплатны и лежат в папке `fonts`.
